# IngeTrazo-Deutsch
Inoffizielle deutsche Sprachdatei (Deutsch.json) für das 3D-Programm IngeTrazo.
Deutsche Übersetzung für IngeTrazo

Dies ist eine inoffizielle deutsche Sprachdatei (`Deutsch.json`) für das Open-Source-Programm **IngeTrazo**.

## Anleitung zur Installation (Windows)

1. Lade dir hier die Datei **`Deutsch.json`** herunter.
2. Gehe in den Installationsordner von *IngeTrazo* (Standardpfad: `C:\Programme\IngeTrazo\` oder wo du es installiert hast).
3. Öffne den Unterordner **`_internal`** und darin den Ordner **`i18n`**.
4. Kopiere die heruntergeladene `Deutsch.json` direkt in diesen `i18n`-Ordner.
5. Starte *IngeTrazo*. In der oberen Menüleiste klickst du auf Window, dann auf Language und wählst Deutsch aus. Danach fordert dich Inge Trazo auf das Programm neu zu starten, um die geänderte Sprachauswahl zu aktivieren. Jetzt sollte alles auf Deutsch angezeigt werden.
